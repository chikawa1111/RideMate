# 동승케어 (RideMate)

> 함께 탄 사람에게 필요한 도움만. 뒷좌석 동승자(영유아·아동·고령자·임산부·거동 불편·반려동물)를 확인해 좌석별 실내 세팅, 안전 경보, 동승자 조건에 맞는 쉬어갈 곳, 하차 확인을 한 번에 제공하는 Pleos Connect 차량용 앱

현대자동차그룹 차량용 앱 개발 공모전 출품작 · 팀 RideMate

## 한 번의 운행 흐름

| 단계 | 화면 | 하는 일 | 차량 API |
|---|---|---|---|
| 등록 | 02 동승자 등록 | 이름·그룹·평소 좌석·앉는 장치(하네스/부스터/안전벨트)·선호 온도·권장 휴식 간격·(학령) 스스로 조작 여부 | — (기기 안에만 저장) |
| 탑승 | 03 탑승 확인 | 착석 센서로 "준서?"처럼 추정 → 운전자 1탭 확정. 게스트·짐 구분 | Seat 착석 |
| 출발 전 | 04 출발 전 확인 | 창문 잠금·공조·열선 자동 적용(같은 공조 존이면 더 취약한 동승자 기준), 벨트·문 닫힘(센서)·카시트·임산부 벨트 위치·차일드락(직접) 확인 | Window 잠금, HVAC 온도, Seat 열선·벨트, Door |
| 주행 | 05 주행 기본 | **A1** 벨트 풀림 3초 지속 시 경보(이름 호명), 권장 휴식까지 남은 시간 표시, 말로 부탁하기(재우기·멀미·조용히·원래대로·쉬어갈 곳). 멀미는 가장 가까운 정차 지점을 바로 보여줌. 재우기 중에는 경고음을 작게, 조용히 중에는 응답 음성만 끔(경보는 항상) | Gear, Seat 벨트, HVAC 풍량·내외기, Light |
| 휴식 | 쉬어갈 곳 | 탑승 구성에 맞는 필수·가점 조건 + 도착 예정이 권장 휴식 시점에 가까운 곳으로 같은 노선·같은 방향 휴게소 상위 2곳. "여기서 쉬었어요"로 휴식 시간 초기화 | — (내장 데이터) |
| 도착 | 08 하차 확인 | 착석 센서로 내림 자동 체크, 동승자별 항목(휠체어·보조기구, 천천히 내리기, 자는 아이 옮기기), **A3** 운전자만 하차, **A2** 차내 잔류(실내등 점등) | Door 열림, Seat 착석, Light |
| 긴급 | 긴급 병원 | 정차 중 홈에서 길 안내 앱의 즐겨찾기·최근 목적지 중 병원을 등록 → 주행 중 "병원 가자"(또는 버튼)로 바로 안내, 20초 안에 "되돌리기"로 원래 목적지 복귀. 임산부가 타면 주행 화면에 긴급 버튼을 늘 표시 | NaviHelper |
| 전 구간 | 날씨·노면 (M12) | 현재 위치 날씨·결빙 위험(추정)·진행 방향 앞 돌발/작업을 화면에만 표시. 비·눈·결빙이면 하차 항목(우산, 바닥 미끄럼)이 늘고, 아이·고령·임산부·거동 불편 동승 시 쉬어갈 곳에서 졸음쉼터를 뺀다. 임시 폐쇄 공지가 있는 쉼터는 제외 | — (외부 API) |

### 설계 원칙
- **앱이 먼저 말을 걸지 않는다.** 모든 기능은 사용자가 부를 때만 동작한다. 예외는 안전 경보 3가지(A1·A2·A3)뿐이며, 끄는 버튼이 없다.
- **음성 우선, 실패하면 버튼(1-a).** 음성 인식을 못 쓰거나 못 알아들으면 같은 기능을 큰 버튼으로 보여주고, 10초 안에 고르지 않으면 조용히 닫는다.
- **모르면 안전한 쪽으로.** 센서 값이 없으면 "남아 있음"으로 본다. 데이터가 없는 휴게소는 권하지 않는다.
- **차량 제어가 실패하면 그 항목만 "직접 해 주세요"로 표시**하고 나머지는 계속한다.
- **지원 여부를 먼저 확인한다.** 홈 화면에 좌석 센서·공조 제어(풍량 capability 확인)·내비 연결 상태를 실제 확인 결과로 보여준다.
- **폭염·한파에는 A2·A3 문구에 바깥 기온을 넣고 5초마다 알린다.** 반려동물이 남아 있으면 차량 펫 모드를 안내한다(시동이 꺼지면 앱은 공조를 유지할 수 없음).

## 실행 방법

1. Android Studio(최신)에서 이 폴더를 엽니다. Gradle JDK는 17 또는 21을 선택합니다.
2. Pleos Connect Emulator v2.1.0(API 34)을 실행합니다.
3. ▶ Run으로 앱을 설치·실행합니다.
4. 버추얼 콘솔: `tools/console_connect.bat` 실행(또는 `adb forward tcp:8088 tcp:8088`) 후 브라우저에서 `http://127.0.0.1:8088/`

### 시연용 조작
버추얼 콘솔에 좌석별 안전벨트와 실제 이동(위치)이 없어서, 주행 화면 아래 **"시연용"** 버튼으로 흉내 냅니다. 시뮬레이션 값은 화면에 "(시뮬레이션)"으로 표시됩니다.
- 주행 / 정차 / 기어 값: 기어를 바꾸지 않고 주행 상태를 흉내 냄 (기어 값 = 실제 기어 센서 사용)
- ○○ 벨트: 좌석별 벨트 체결 상태 전환
- 위치: 시연용 위치 3곳(영동선·경부선·서해안선) → 내비 현재 위치 순환
- 날씨: 실제 → 비 → 눈·결빙 → 폭염 순환 / 도로: 실제 ↔ 앞 7km 작업
- 시간 +30분: 권장 휴식 표시를 확인하기 위해 시간을 앞당김

## 사용 SDK·API

| SDK | 용도 |
|---|---|
| Vehicle – Seat | 좌석별 착석·안전벨트, 좌석 열선 |
| Vehicle – Window | 뒷좌석 창문 잠금 |
| Vehicle – HVAC | 좌석 존 온도, 풍량, 내·외기 (재우기·멀미 장면, 원래대로 복원) |
| Vehicle – Door | 문 열림(하차 확인, A2·A3) |
| Vehicle – Light | 실내등(A2 점등, 재우기 소등) |
| Vehicle – Gear | 주행/정차 판단 |
| NaviHelper 3.0.5 | 현재 위치·진행 방위, 목적지 남은 시간("다 왔어?"), 쉬어갈 곳 → 경유지 추가/안내 시작, 편안한 경로(COMFORTABLE), 목적지 도착 → 하차 확인 자동 시작, 휴식지 도착 → 휴식 시간 초기화, 즐겨찾기·최근 목적지 → 긴급 병원 등록, 긴급 병원 바로 안내·되돌리기 |
| Android TextToSpeech | 경보·응답 음성 (Pleos TTS 공개 전 대체) |

## 실시간 외부 데이터 (M12)

| 데이터 | 출처 | 키 |
|---|---|---|
| 현재 날씨·6시간 강수확률·기온 | Open-Meteo forecast API | 없음 |
| 고속도로 실시간 돌발·작업·기상 상황(위경도 포함) | 한국도로공사 공공데이터 포털 `burstInfo/realTimeSms` | `local.properties`의 `EX_API_KEY` (없으면 포털 공개 테스트 키) |

판정 기준(앱 기준): 결빙 위험 = 기온 2℃ 이하 + 최근 6시간 강수 또는 습도 90% 이상 · 우산 = 비·눈 또는 6시간 강수확률 60% 이상 · 앞쪽 = 같은 노선·같은 방향·30km 이내. 조회 실패 시 이전 값을 "최신 아님"으로 표시하고, 날씨·노면으로는 소리를 내지 않는다.

| 버추얼 콘솔에 좌석별 벨트·뒷좌석 가운데·이동 위치 없음 | 콘솔 확인 | 시연용 조작(화면에 표시) |

## 한계 (구현하지 않은 것)
- 쉬어갈 곳 후보의 거리는 직선 거리다(고른 뒤의 실제 경로·시간은 내비가 계산).
- 차일드락은 조회·제어 API가 없어 체크리스트 항목으로만 둔다.
- 시동이 꺼진 뒤의 차내 잔류 감지는 앱 영역이 아니다(차량 후석 승객 알림 기능의 영역).
- 하네스 카시트는 차량 벨트 센서로 확인할 수 없어 벨트 경보 대상에서 제외하고 출발 전에 직접 확인한다.
